# Спектаторский HUD — Style Reference
> тёмная арена наблюдателя с лазерной пульсацией — интерфейс смотрит на игрока так, как обсервер смотрит на матч: панели-плашки со срезанными углами, HUD-уголки захвата цели и три семантических цвета вердикта на угольно-синем поле.

**Theme:** dark (единственная тема; кадры-улики из игры тёмные — светлой темы нет намеренно)

Система живёт на угольно-синем поле #0d1117 с едва заметной диагональной штриховкой, как карбоновая текстура оверлея трансляции. Поверхности — плоские панели #151c26 без теней и почти без рамок; форма задаётся срезанными углами (clip-path), а не радиусами. Цвет строго семантический и неприкосновенный: красный #ff4655 = «мимо», янтарный #ffb454 = «гипотеза», зелёный #3ddc97 = «в цель» — декоративных акцентов нет вовсе. Типографика трёхголосая: Russo One кричит заголовками, как никнейм на экране загрузки, Manrope спокойно объясняет, JetBrains Mono бормочет телеметрию. Движение оркестровано, а не рассыпано: загрузочный каскад, лазер под ключевым словом, «обойма» серьёзности, заряжающаяся деление за делением, и уголки, захватывающие карточку при наведении.

## Tokens — Typography

### Russo One — голос диктора · `--font-display`
- **Substitute:** Black Ops One, Jura (bold)
- **Weights:** 400 (единственный)
- **Sizes:** 14px (заголовки карточек), 17px (H2, бренд), 20px (номера контрактов), clamp(30px, 5vw, 54px) (H1)
- **Line height:** 1.1 (H1), 1.2 остальное
- **Letter spacing:** 0.04–0.08em, всегда uppercase
- **Role:** Только заголовки, бренд и номера. Широкий гротеск с характером киберспортивной трансляции. Никогда не используется для текста длиннее одной строки.

### Manrope — голос объяснения · `--font-body`
- **Substitute:** Segoe UI, system-ui
- **Weights:** 400 (текст), 600 (подзаголовки полей), 800 (CTA, лиды)
- **Sizes:** 13–15px основной текст
- **Line height:** 1.6
- **Role:** Весь связный текст: объяснения коуча, лиды находок, подсказки формы. Единственный голос, которому разрешён mixed case.

### JetBrains Mono — голос телеметрии · `--font-mono`
- **Substitute:** Consolas, ui-monospace
- **Weights:** 400, 700 (крупные числа)
- **Sizes:** 10px (бейджи), 11px (kill-feed, подписи кадров, статус), 30px (числа severity)
- **Letter spacing:** 0.06–0.14em, uppercase на подписях
- **Role:** Всё, что «пишет машина»: числа движка, номера кадров, метаданные клипа, футер-мантра. HU-числа — только этим шрифтом.

## Tokens — Spacing & Shapes

**Density:** comfortable; воздух между секциями большой, внутри панелей — плотно.

### Spacing Scale

| Name | Value | Роль |
|------|-------|------|
| xs | 8px | зазор внутри строк телеметрии |
| sm | 14px | зазоры чипов, делений |
| md | 18px | gap бенто-сетки и контрактов |
| lg | 26px | паддинг карточек |
| xl | 48px | вертикальный паддинг секций |
| hero | 72px / 56px | верх/низ hero |

### Форма: срез вместо радиуса

Сигнатура системы — **срезанный угол**, а не скругление:

```css
--cut: polygon(10px 0, 100% 0, 100% calc(100% - 10px),
       calc(100% - 10px) 100%, 0 100%, 0 10px);
```

| Element | Форма |
|---------|-------|
| Кнопки, CTA | clip-path `--cut` |
| Бейджи, чипы, статус-пилюля | clip-path `--cut` |
| Kill-feed плашка | clip-path `--cut` + левый борт 3px `--miss` |
| Контракты | clip-path `--cut` + левый борт 3px `--miss` |
| Карточки-находки (tiles) | прямые углы, БЕЗ среза — их держат HUD-уголки |
| Кадры-улики | прямые углы |

**Правило:** срез = интерактив и плашки-ярлыки; прямой угол = контент. Радиусов нет нигде, кроме круглой точки статуса.

### Layout

- **Page max-width:** 1140px, паддинг 24px
- **Section padding:** 48px по вертикали
- **Бенто-сетка:** 3 колонки, главная находка `span 2 × span 2`, широкая — `span 3`; на ≤860px — одна колонка

## Tokens — Motion

Движение — часть идентичности, оно оркестровано в три слоя.

| Token | Value | Роль |
|-------|-------|------|
| `--fast` | 180ms cubic-bezier(0.2, 0.8, 0.3, 1) | микро: уголки, кнопки, hover |
| `--rise` | 600ms cubic-bezier(0.16, 1, 0.3, 1) | вход блоков (каскад) |
| stamp | 300ms cubic-bezier(0.34, 1.56, 0.64, 1) | печать контракта (лёгкий overshoot) |

1. **Загрузка (hero):** kill-feed (80ms) → H1 (220ms) → лид (420ms) → CTA (560ms); лазер прочерчивается под ключевым словом на 900ms за 700ms. Призрачный прицел вращается всё время (46s/80s, встречные направления).
2. **Скролл:** карточки входят каскадом `.rv → .rv.in` (сдвиг 18px, стагер 90ms); обойма заряжается деление за делением (стагер 80ms, старт 350ms после входа); печати контрактов «пропечатываются» (scale 1.12 → 1).
3. **Микро:** HUD-уголки стягиваются к центру на 5px при hover; точка статуса «дышит» сонаром (ореол расходится 3.6s) — никогда не мигает.

**Reduced motion:** при `prefers-reduced-motion: reduce` весь контент виден сразу, обойма заряжена, лазер прочерчен, ничего не движется. Это обязательный, не опциональный фолбэк.

## Components

### Masthead
**Role:** шапка каждого экрана

Слева бренд «АИМ-ПАСПОРТ» (Russo One 17px, дефис красный `--miss`). Справа статус-пилюля: панель со срезом, JetBrains Mono 11px uppercase, внутри зелёная точка-сонар и текущий контекст («КЛИП CLIP2 · ИГРОК FRIEND»). Под шапкой — tick-rule.

### Tick Rule
**Role:** разделитель-риска

1px линия `--line` с вертикальной риской 1×9px `--dim` точно по центру — след прицела, преемственность со старой версией сайта. Используется под шапкой и над футером.

### Kill-feed плашка
**Role:** эйбрроу hero, задаёт тон с первой строки

Панель со срезом, левый борт 3px `--miss`, JetBrains Mono 11px uppercase с трекингом 0.12em: `ДВИЖОК ✕ <жертва>` — формат килл-фида Valorant, где «жертвой» становится проблема игрока.

### Hero H1 + лазер
**Role:** тезис страницы

Russo One clamp(30–54px) uppercase. Ключевое слово — контуром (`-webkit-text-stroke: 1.5px --paper`, заливка прозрачная) и с лазерным подчёркиванием: линия 2px `--miss` со свечением `0 0 12px rgba(255,70,85,0.7)`, прочерчивается слева направо после появления заголовка.

### Ghost Crosshair
**Role:** ambient-фон hero

SVG-прицел 480px в правой части hero на opacity 0.05: внешнее кольцо статично, два внутренних пунктирных кольца вращаются в противоположные стороны (46s и 80s). На ≤860px скрыт.

### CTA
**Role:** единственная залитая кнопка системы

Заливка `--miss`, белый текст Manrope 800 uppercase 14px, срез `--cut`, паддинг 14×34px. Hover: brightness(1.12) + подъём на 1px. Красную заливку не имеет больше НИ ОДИН элемент интерфейса.

### HUD-уголки («захват цели»)
**Role:** ключевая микро-интеракция карточек

Четыре уголка 15×15px, 2px `--dim`, сидят на углах карточки. При hover карточка приподнимается на 2px, уголки стягиваются на 5px к центру и перекрашиваются в цвет вердикта карточки (`--verdict`, дефолт `--paper`) — как захват цели спектаторской камерой. У карточки главной проблемы (`is-target`) уголки красные постоянно.

### Bento Tile (находка)
**Role:** карточка вердикта движка

Фон `--panel` (главная — `--panel-up`), паддинг 26px, прямые углы, HUD-уголки. Внутри: бейдж уверенности в правом верхнем углу, заголовок Russo One 14px, объяснение Manrope `--dim`, severity-обойма, кадры-улики. Вердикт-класс `v-miss / v-hypo / v-hit` задаёт `--verdict` и `--halo`.

### Бейдж уверенности
**Role:** маркер диагноз/гипотеза/мало данных

JetBrains Mono 10px uppercase, срез `--cut`. Уверенность кодируется формой, не только цветом: **диагноз** — сплошная заливка `--paper`, текст `--field`; **гипотеза** — заливка `--hypo`, текст `--field`; **мало данных** — пунктирная рамка `--dim` без заливки.

### Severity-обойма
**Role:** визуализация `severity_ratio` движка (отклонение находки от её собственного порога)

Крупное число JetBrains Mono 700 30px в цвете вердикта со свечением (`3.33×` + подпись «от порога») и 10 скошенных делений 7×20px (skewX −12°). Заряжено `round(severity_ratio × 5)` делений: **порог = середина обоймы (5 делений), полная обойма = 2× порога.** Деления заряжаются по одному при входе карточки в вьюпорт. Вердикт из того же числа: `< 1` → hit, `1–2` → hypo, `≥ 2` → miss. Число берётся ТОЛЬКО из `severity_ratio` evidence-JSON — фронт его не вычисляет.

### Кадр-улика
**Role:** доказательство находки

Тёмный контейнер 16:9 с прямыми углами; по кадру раз в 7s проходит медленный блик (как отсвет монитора). Подпись — JetBrains Mono 11px: слева `КАДР 177`, справа заметка движка. Клик открывает лайтбокс (Esc / клик мимо — закрыть).

### Контракт (дрилл)
**Role:** одна тренировка из плана коуча

Панель со срезом и левым бортом 3px `--miss`. Номер Russo One 20px `--miss` (01, 02 — это реальный приоритет), название Manrope 800, дозировка JetBrains Mono 11px uppercase, чипы платформы/tier. Внизу — **печать**: пунктирная рамка, текст критерия успеха цветом `--hit` с галочкой `✓`; при входе в вьюпорт «пропечатывается» (scale 1.12 → 1, задержка 500ms).

### Footer
**Role:** мантра проекта

Над футером tick-rule. Две реплики по краям, JetBrains Mono 11px uppercase `--dim`: «ЧИСЛА СЧИТАЕТ ТОЛЬКО ДВИЖОК» / «КОУЧ ОБЪЯСНЯЕТ · НЕ ИЗМЕРЯЕТ».

## Do's and Don'ts

### Do
- Кодируй смысл цветом строго по семантике: красный = «мимо»/проблема, янтарный = гипотеза/осторожность, зелёный = «в цель»/критерий успеха
- Дублируй смысл формой: диагноз — сплошное, гипотеза — пунктир (бейджи, рамки печатей) — цвет никогда не единственный носитель
- Используй срез `--cut` на всём интерактивном и на плашках-ярлыках; контентные карточки держи прямоугольными с HUD-уголками
- Все числа движка (HU, severity, номера кадров) — только JetBrains Mono; Russo One — только для заголовков в одну строку
- Оркеструй вход: каскад с нарастающими задержками, один сценарий на страницу
- Свечение (`box-shadow`/`text-shadow` с ореолом вердикта) — только на severity-числах, делениях обоймы и лазере
- Показывай в обойме только `severity_ratio` из evidence-JSON движка

### Don't
- Не вводи новых акцентных цветов и не используй семантические цвета декоративно (красная иконка «для красоты» — запрещено)
- Не заливай красным ничего, кроме CTA: красная заливка = «главное действие», и она одна на экран
- Не скругляй углы — в системе нет border-radius, кроме круглой точки статуса
- Не добавляй теней глубины (box-shadow-elevation) — поверхности разделяются только тоном (#0d1117 → #151c26 → #1b2432)
- Не заставляй ничего мигать: точка статуса дышит сонаром, никакого blink
- Не растягивай Russo One на абзацы и не пиши им mixed case
- Не вычисляй severity и вердикты на фронте из сырых HU — бери готовый `severity_ratio` движка
- Не оставляй анимации без reduced-motion фолбэка «всё видно сразу»

## Elevation

Система отказывается от теней глубины. Иерархия поверхностей — только тональная (три ступени). Единственное «свечение» — семантические ореолы вердиктов на severity-числах, заряженных делениях обоймы и лазере: это не elevation, а сигнал прибора. Hover-подъём карточек — transform на 2px без тени.

## Imagery

Единственные изображения системы — кадры-улики движка: реальные скриншоты геймплея с аннотированными боксами голов. Они и есть визуальный центр продукта, поэтому декоративных иллюстраций, фото и иконографики нет. Кадры всегда 16:9, с мониторным бликом раз в 7s, подписаны номером кадра в mono. Вне кадров образность абстрактно-прицельная: ghost-прицел, риски, уголки захвата.

## Layout

Одноколоночная страница 1140px с бенто-вставками. Порядок подачи — как у обсервера: шапка со статусом → hero-тезис с kill-feed → бенто вердиктов (главная проблема занимает 2×2, остальные — по клетке, «чистая» метрика — широкой полосой) → контракты 2×2 → футер-мантра. Асимметрия бенто = приоритет движка: размер клетки пропорционален важности находки. Навигации нет — это одностраничный отчёт, сессия живёт в URL.

## Typographic Register System

Три голоса, никогда не смешиваются:

- **Голос диктора** — Russo One, uppercase, только заголовки и номера. Это то, как система звучит со сцены.
- **Голос объяснения** — Manrope 400/600/800, mixed case. Всё, что говорит коуч человеку: лиды, объяснения, подсказки. Единственный голос, которому можно писать предложениями.
- **Голос телеметрии** — JetBrains Mono, uppercase на подписях. Всё, что измерил движок: числа, кадры, статусы, футер-мантра. Читатель должен без подсказки отличать «сказал коуч» от «померил движок» — по шрифту.

Заголовок в mono сломает регистр так же, как HU-число, набранное Manrope.
