# Источники — каталог по механизму доступа к коду

Резка по тому, **как агент добирается до кода**, а не по категориям — каждая
группа отвечает на вопрос «откуда здесь берётся реальный код». Проверено
`WebFetch`/`gh` 2026-07-16 в этой сессии; где отмечено «не проверено» — свериться
в документации источника перед использованием, не подставлять по памяти.

## 1. Готовые спеки — забираются как есть

**styles.refero.design** — 2000+ машиночитаемых дизайн-систем реальных
продуктов. У каждого стиля свой `DESIGN.md`: цвета, типографика, спейсинг,
компоненты, готовый блок для вставки в Cursor/Claude Code/v0.

- Приём: назван стиль или дана ссылка → `WebFetch` его `DESIGN.md` → верстать
  строго по токенам оттуда.
- Каталог: `https://styles.refero.design/`, стиль: `/style/<uuid>`.
- Refero MCP — использовать, если подключён (даёт живые экраны продукта и флоу).

## 2. shadcn-реестры — агент читает код сам, без обязательной установки

Общий механизм на всю группу:

```bash
npx shadcn@latest view @magicui/marquee              # прочитать код ДО установки — ничего не ставит
npx shadcn@latest search @magicui --query "text"      # поиск по реестру
npx shadcn@latest add @magicui/marquee                # установить
```

`view` — read-only и работает даже в проекте без Tailwind/`components.json`:
если ставить рано или некуда, код всё равно можно прочитать и перенести вручную
на чистый CSS/JS. Это и есть ответ на «где взять реальный код», а не запрет на
установку.

Реестры объявляются в `components.json`, namespace выбирается самостоятельно —
настоящий идентификатор реестра это URL, а не имя после `@`:

```json
{
  "registries": {
    "@magicui": "https://magicui.design/r/{name}.json",
    "@aceternity": "https://ui.aceternity.com/registry/{name}.json"
  }
}
```

**Проверенные точки входа (2026-07-16, прямым запросом к JSON):**
- Magic UI — `https://magicui.design/r/{name}.json` (пример: `.../r/globe.json` — валидный item-файл реестра). Также подключается напрямую командой из их доков: `npx shadcn@latest add @magicui/<name>`.
- Aceternity UI — `https://ui.aceternity.com/registry/{name}.json` (пример: `.../registry/globe.json` — валидный item-файл).
- shadcn blocks (первая сторона) — `ui.shadcn.com/blocks`, пример команды из их доков: `npx shadcn add dashboard-01`.
- **react-bits.dev теперь тоже в этой группе**, не только в «сниппетах» (см. §3 — раньше был только копипаст, реестр появился позже): `npx shadcn@latest add @react-bits/<Component>-<Variant>` (варианты: `-JS-CSS`, `-JS-TW`, `-TS-CSS`, `-TS-TW`). Лицензия из §3 (MIT + Commons Clause) действует независимо от способа установки.

**Не проверено в этой сессии, свериться в доках при использовании:** Motion
Primitives, Cult UI — тот же механизм (реестр + `view`/`add`), конкретный
registry-URL в их официальной документации по установке. Поиск реестров:
`registry.directory` (подтверждён — агрегатор сторонних shadcn-реестров).

## 3. Сниппеты — код лучше доставать напрямую, не по памяти

- **uiverse.io** — кнопки, чекбоксы, тогглы, карточки, лоадеры на чистом
  CSS/Tailwind. Лицензия **MIT** (подтверждено через их GitHub-организацию
  `uiverse-io`, репозиторий `galaxy`) — код можно брать напрямую, атрибуция не
  обязательна лицензией, но уместна.
  Сам сайт **блокирует `WebFetch`** (403, не просто «отдаёт мета-теги» — доступа
  нет вообще): код доставать через GitHub-организацию `uiverse-io` или
  попросить пользователя прислать сниппет.
- **reactbits.dev** — 140+ анимированных React-компонентов; сильнее всего фоны
  (Aurora, Beams, Particles — WebGL) и анимации текста. Устанавливается и через
  shadcn-реестр (см. §2), и вручную (сайт даёт готовый код на выбор
  JS/TS × CSS/Tailwind). Лицензия репозитория `DavidHDev/react-bits` — **MIT +
  Commons Clause v1.0** (подтверждено по факту, дословно): использовать можно
  свободно, включая коммерчески, **но нельзя продавать, сублицензировать или
  редистрибутировать сами компоненты** — отдельно, в сборке или в портированном
  виде.
  MCP-серверы для react-bits существуют, но **неофициальные**
  (сторонние проекты вроде `duolabstech/react-bits-mcp-server`) — не
  официальный канал автора, проверить актуальность перед использованием.

## 4. Галереи — для человека, не для агента

Отсюда код не достаётся — агент сюда не ходит за реализацией, смотрит
пользователь и присылает ссылку/скриншот.

- **Awwwards**, **siteinspire** — подтверждены, витрины веб-дизайна для
  визуального просмотра, кода не дают.
- **Mobbin**, **Land-book** — блокируют автоматический доступ (403 на прямой
  запрос), но по названию и общеизвестному назначению — тоже галереи скриншотов
  реальных продуктов/лендингов для человека, не для агента.
- ~~**Godly**~~ — красноречивый пример протухания прямо во время написания
  этого каталога: `godly.website` при запросе 2026-07-16 отдаёт `301` на
  `recent.design`. Использовать `recent.design`, не `godly.website`.

## 5. Системный слой — инструменты, другая ось резки

Не про источники кода — про подготовку токенов до вёрстки:

- **tweakcn** (`tweakcn.com`) — редактор тем shadcn/ui, живое превью, экспорт в Tailwind.
- **Realtime Colors** (`realtimecolors.com`) — палитра и шрифты на живом макете сайта.
- **Fontshare** (`fontshare.com`) — бесплатные шрифты; коммерческие условия не
  подтверждены с одной домашней страницы — проверять лицензию конкретного
  шрифта на его странице перед использованием в платном продукте.
- **Lucide** (`lucide.dev`) — независимый набор иконок (ISC-лицензия); **не
  входит в комплект shadcn/ui буквально**, но это иконки по умолчанию в
  стандартных шаблонах shadcn — уточнение важнее, чем «идёт в комплекте».

## 6. Протухание

Источники меняются быстрее, чем кажется — за время написания одного этого файла
поймано два случая:

1. **Godly → recent.design** — домен целиком переехал, `301`-редирект (см. §4,
   поймано 2026-07-16).
2. **react-bits.dev обзавёлся shadcn-реестром** — раньше был только
   копипаст-сниппет (см. §3), теперь у него есть `npx shadcn add @react-bits/…`
   — источник не переехал, но сменил механизм доступа.
3. Origin UI, по независимым данным, за прошлый год стал **coss ui** и
   переехал на Base UI: `coss.com/ui` (подтверждено — «built on top of Base
   UI», 500+ компонентов) и легаси-путь `coss.com/origin` (подтверждено,
   существует и посвящён origin-каталогу) — оба живы. Сам `originui.com`
   на прямой запрос отдаёт `403`, поэтому факт редиректа со старого домена
   в этой сессии **не подтверждён** напрямую — если это важно для конкретной
   задачи, проверить отдельно, не считать подтверждённым по одной этой записи.

Отсюда правило: каталог хранит **механизмы и стабильные точки входа**, а не
заученные списки версий. Если источник не отвечает, ведёт себя не так, как
здесь написано, или переименовался — сказать вслух и проверить заново, а не
воспроизводить по памяти этот файл.
