# Multivariant Web Design

## Overview

Для визуальной задачи не существует одного «правильного» макета — есть
направления с разным характером, которые нужно сравнить вживую. Этот навык
всегда собирает три заметно разных варианта, а не один макет в трёх цветах.

## Главное правило: 3 варианта

Всегда собирай три отдельных, ощутимо разных направления — это не факультативная
опция и не зависит от того, попросил ли пользователь выбор явно:

- **A. Продуктовый** — в духе refero: выверенная сетка, строгая иерархия,
  спокойная типографика.
- **B. Живой** — в духе reactbits: анимация, движение, интерактивные фоны.
- **C. Характерный** — в духе uiverse: свечения, градиентные бордеры,
  выразительные детали.

Различие — в композиции и характере, не только в акцентном цвете.

## Подача

Отдавай варианты файлами, которые открываются в браузере:

```
design-variants/
  index.html        # переключатель между вариантами
  a-product.html
  b-alive.html
  c-character.html
```

Открой `index.html`. К каждому варианту — 1–2 фразы: настроение, акцент, кому
подойдёт.

## Источники

Нужен источник, стиль назван или дана ссылка → читай `references/sources.md` —
там каталог точек входа по механизму доступа к коду.

**Не воспроизводи чужой компонент или стиль по памяти.** Даже если уверенно
помнишь цвета и структуру — загрузи реальную спеку, прочитай код источника или
попроси пользователя прислать его. Уверенная память — не то же самое, что
проверенный факт.

## Рабочий процесс

1. Контекст неясен — задай 1–2 уточняющих вопроса.
2. Выбери тему (тёмная/светлая) осознанно, не по умолчанию.
3. Есть зацепка (продукт, бренд, реальные данные) — подтяни её, не выдумывай.
4. Собери три варианта по правилу выше и по качеству вёрстки (см. ниже).
5. Подпиши различия между вариантами и предложи следующий шаг.

**REQUIRED SUB-SKILL:** Use frontend-design для токенов, типографики и отступов.

## Чек-лист перед выдачей

- [ ] Три файла в `design-variants/`, не один.
- [ ] Варианты заметно различаются по композиции и характеру, не только цветом.
- [ ] Есть `index.html`-переключатель.
- [ ] К каждому варианту — короткое пояснение (настроение/акцент/кому подойдёт).
- [ ] Тема выбрана осознанно.
- [ ] Ни один компонент или стиль не воспроизведён по памяти без попытки достать
      источник.
