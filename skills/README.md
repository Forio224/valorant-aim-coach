# Skills

Каталог навыков (skills) для этого проекта. Каждый навык — это папка с
инструкциями для Claude Code, которая описывает, как выполнять определённый класс
задач. Навык подключается автоматически, когда запрос пользователя совпадает с
триггерами из его `SKILL.md`.

## Как устроен навык

Каждая папка навыка содержит как минимум `SKILL.md` с YAML-фронтматтером:

- `name` — идентификатор навыка (совпадает с именем папки);
- `description` — когда навык применять (триггеры на RU/EN), по этому полю
  Claude решает, релевантен ли навык запросу.

Дополнительные файлы (`PLAN.md`, `DESIGN.md`, `BASELINE.md`, `references/…`) —
это рабочие материалы и справочники, на которые ссылается `SKILL.md`.

### multivariant-web-design

**Что делает:** на любую визуальную задачу (лендинг, страница, экран, форма,
дашборд, UI-компонент) собирает **три отдельных, ощутимо разных варианта
дизайна** — не один макет в трёх цветах, а три разных направления по композиции
и характеру:

- **A. Продуктовый** — выверенная сетка, строгая иерархия, спокойная типографика
  (в духе refero).
- **B. Живой** — анимация, движение, интерактивные фоны (в духе reactbits).
- **C. Характерный** — свечения, градиентные бордеры, выразительные детали
  (в духе uiverse).

**Что на входе:** просьба «сделай страницу / свёрстай / дизайн лендинга /
набросай интерфейс / сделай красиво» (RU/EN), в т.ч. без явного слова «дизайн» и
без референсов. Также срабатывает, если назван стиль продукта («как Linear», «в
стиле Vercel») или дана ссылка на uiverse.io, reactbits.dev,
styles.refero.design.

**Что на выходе:** папка `design-variants/` с файлами, которые открываются в
браузере:

```
design-variants/
  index.html        # переключатель между вариантами
  a-product.html
  b-alive.html
  c-character.html
```

К каждому варианту — короткое пояснение (настроение, акцент, кому подойдёт).

**Ключевые правила:**

- Всегда три варианта — это не опция, не зависит от того, просил ли пользователь
  выбор явно.
- Чужой компонент или стиль **не воспроизводится по памяти** — источник
  подтягивается реально (спека, код, ссылка).
- Тема (тёмная/светлая) выбирается осознанно, а не по умолчанию.
- Использует под-навык `frontend-design` для токенов, типографики и отступов.

**Когда НЕ применять:** бэкенд, алгоритмические или чисто текстовые задачи без
визуального результата; вставка одного готового компонента из реестра в
существующее приложение.

## Как добавить новый навык

1. Создай папку `skills/<имя-навыка>/` с файлом `SKILL.md`
   (фронтматтер `name` + `description`, затем инструкции).
2. При необходимости добавь вспомогательные файлы и `references/`.
3. Допиши строку в таблицу «Каталог навыков» и раздел с описанием выше.
